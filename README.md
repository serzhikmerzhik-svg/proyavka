# Проявка

Веб-дневник, который «проявляет» атмосферу дня: **цвет — из фото, свет — из слов, ритм — из песни.**
Вечером человек пишет текст, прикладывает 1–6 фото и выбирает песню — и получает отпечаток, который проявляется
в тёмной комнате под эту песню, а потом «живёт»: параллакс по карте глубины, частицы воздуха в такт, озвучка.

## Быстрый старт

Нужен Node.js 20.12+.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 (клиент, Vite). API — http://localhost:8787, Vite проксирует на него `/api/*`.

**Без ключей всё работает в демо-режиме:** анализ текста — эвристика по ключевым словам, озвучка выключена.
На пустом контактном листе нажмите «Загрузить 5 демо-дней». Блок «Год назад» для демо:
http://localhost:5173/?today=2026-11-19

```bash
npm test          # 42 теста: анализ с повтором и откатом, озвучка, правила рецепта, процессы, композиции, ZIP, демо-дни
npm run typecheck
```

## Продакшен: один сервис

```bash
npm run build
npm start
```

Express раздаёт `client/dist` и `/api/*` на одном порту (`PORT`, по умолчанию 8787) — http://localhost:8787.
Для хостинга Node (Render, Railway, Fly): сборка `npm install && npm run build`, запуск `npm start`.

## Переменные окружения

Скопируйте `.env.example` → `.env` в корне. Все ключи — только на сервере.

| переменная | значение |
|---|---|
| `API_PORT` | порт API в dev, по умолчанию 8787 |
| `PORT` | порт в продакшене (API + клиент), по умолчанию 8787 |
| `LLM_PROVIDER` | `anthropic` / `openai` / `none`; пусто — по найденному ключу, нет ключа — эвристика |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `ANTHROPIC_EFFORT` | Claude; по умолчанию `claude-opus-5-5`, усилие `low` |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | OpenAI для анализа; по умолчанию `gpt-4.1-mini` |
| `LLM_TIMEOUT_MS` | таймаут одного запроса к модели, по умолчанию 60000 |
| `TTS_PROVIDER` | `openai` / `yandex` / `none`; пусто — OpenAI, если есть `OPENAI_API_KEY` |
| `TTS_MODEL`, `OPENAI_TTS_VOICE` | по умолчанию `gpt-4o-mini-tts`, голос подбирается по атмосфере; можно зафиксировать снимок модели |

## Как это устроено

```
client/  Vite + React + TypeScript + three.js
  src/analysis/   фото (EXIF, палитра), музыка (темп, доля, RMS, тональность), глубина (воркер), пайплайн
  src/recipe/     типы, пресеты 9 процессов, buildRecipe (§5), why[], проверки подписи и названия
  src/render/     шейдер, рендерер, композиции, сцена отпечатка, компоновщик рамки, запись видео
  src/audio/      граф Web Audio (музыка + голос), часы долей, озвучка
  src/storage/    IndexedDB (Dexie), ZIP папки дня, демо-дни
  public/demo/    5 демо-дней
  scripts/        сборка демо-дней
server/  Express + TypeScript
  src/llm/        Claude / OpenAI: промпт, JSON-схема, провайдеры
  analyze.ts      /api/analyze: модель → zod → один повтор → эвристика
  music.ts        поиск Deezer (запасной iTunes), детали трека, прокси превью
  tts.ts          /api/tts: озвучка со стилем из recipe.voice
```

### Анализ дня (§4)

- **Песня:** поиск «исполнитель — название» или ссылка (Deezer, Apple Music, Spotify/YouTube/SoundCloud через oEmbed),
  подтверждение по обложке. Превью проксируется на лету и не сохраняется.
- **Музыка в браузере:** темп и первая доля (`web-audio-beat-detector` + своя проверка октавы по басу — медленные песни
  не удваиваются, быстрые не делятся), огибающая RMS, спектральный центроид, тональность по Крумхансл — Кесслеру, эпоха.
- **Текст и кадры:** `/api/analyze` — Claude или OpenAI со structured outputs по общей JSON-схеме, проверка zod,
  ровно один повтор, затем эвристика. Клиент сам проверяет дословность подписи и название папки.
- **Глубина:** Depth Anything V2 Small в Web Worker (WebGPU, запасной WASM), считается в фоне после сохранения дня.

### Рецепт (§5) и рендер (§6)

`buildRecipe` детерминирован: оси (0,6·слова + 0,4·музыка; 0,7·слова + 0,3·лад), два ближайших процесса
с весами по обратному расстоянию, сплит-тон противоречия, свет, ритм (такт, длина кадра, склейки/наплывы),
композиция, частицы, подпись, голос, `why[]`. Ползунки «тише ↔ ярче», «тяжелее ↔ светлее» пересобирают рецепт.

Один шейдер на 9 процессов: пресеты — векторы параметров, смешиваются на CPU. Зерно зависит от яркости и меняет
seed на каждой доле, у трихрома каналы расходятся на долях. Живой снимок: параллакс `uv + (depth − 0.5)·uParallax`
от курсора или гироскопа (на iOS — запрос разрешения по касанию), туман по глубине, процедурные пар, листья, снег,
дождь и пыль с плотностью от RMS. Композиции: single, diptych, sequence, strip, contact_sheet с красным кружком
«кадра дня» (затем sequence). Рамка одинакова у всех дней: 4:5, фигурный край, штамп DSEG7, подпись Caveat.

`/lab` — одно фото всеми 9 процессами (3 × 3) и смешивание двух процессов по весам; `/lab/music` — темп и тональность.

### Озвучка (§8), видео и папка дня (§7)

- После проявки звучит озвучка текста (mp3 сохраняется в дне), музыка на это время приглушается.
- «Записать видео» — MediaRecorder пишет проявку (canvas + музыка + голос) в webm, сохраняется в день.
- «Скачать папку» — ZIP `YYYY-MM-DD Название/`: `text.md`, `photos/`, `depth/`, `song.json` (без аудио),
  `recipe.json`, `print.png`, `voice.mp3` и `memory.webm`, если есть.

> В `memory.webm` попадает звук превью песни — это расходится с §9 («песни не храним и не раздаём»).
> Если для сдачи это важно, уберите музыку из записи: в `SongPlayer.recordingTrack()` подключайте к записи только голос.

## Демо-дни

`client/public/demo/<slug>/`: `day.json` (дата, текст, песня), `analysis.json` (смысл дня, как его вернула бы модель,
и признаки песни), `photos/*.jpg`, `recipe.json` (собирается скриптом). Сейчас фото — процедурные заглушки.

Как заменить на свои:

1. Положите свои JPEG в `photos/` (старые удалите), поправьте `text` и `date` в `day.json`.
2. Если сменили песню — возьмите ID из поиска и снимите признаки на `/lab/music`, впишите их в `analysis.json → music`.
3. Пересоберите: `npm run demo:build` (палитры и рецепты) или `npm run demo:build -- --reanalyze`
   (ещё и заново разобрать тексты эвристикой). Тест проверяет, что `recipe.json` не устарел.
4. В приложении: «Убрать демо-дни» → «Загрузить демо-дни».

## ИИ-оживление (опция, по умолчанию выключена)

Сознательное исключение из §9: кадр дня можно отправить в видео-API (Kling image-to-video), чтобы нейросеть
дорисовала 5 секунд движения деталей (синемаграф: камера неподвижна, двигаются пар, листья, снег — то, что есть
в рецепте). Включается только `VIDEO_PROVIDER=kling` с ключами Kling; ключи сами по себе опцию не включают.

Сервер: `POST /api/animate` (задача), `GET /api/animate/:taskId` (статус),
`GET /api/animate/:taskId/video` (mp4 через сервер: ссылки Kling короткоживущие). JWT HS256, промпт, ошибки,
тесты на подставном fetch. Клиент: кнопка «✦ Оживить детали» на экране проявки — подтверждение (кадр уходит во
внешний сервис), прогресс с секундомером, видео проверяется и сохраняется в день, после проявки идёт в шейдер вместо
кадра (петля растворяется в неподвижный кадр — шва не видно), пометка «✦ ИИ-оживление» на поле отпечатка и в записи,
`motion.mp4` и строка в `text.md` в папке дня. Путь проверен на подставном сервере; живой вызов Kling — нет ключей.

## Онлайн-версия без сервера (GitHub Pages)

`.github/workflows/pages.yml` собирает клиент с `BASE_PATH=/<репозиторий>/` и публикует на GitHub Pages при каждом
пуше в `main`. Без сервера работают: вход, демо-дни, свои дни (анализ текста — та же эвристика, что на сервере, прямо
в браузере; песня — свой аудиофайл или «исполнитель — название»), девять процессов, глубина и параллакс, запись
проявки, папка ZIP. Только с сервером: анализ моделью, поиск песен и превью, озвучка, ИИ-оживление —
`npm run build && npm start`.

## API

- `GET /api/health` — какой провайдер анализа и озвучки активен (или почему нет)
- `POST /api/analyze` — анализ текста и кадров: модель по схеме → повтор → эвристика
- `POST /api/tts` — mp3 озвучки (`text`, `style`, `speed`, `mood`); 503, если озвучка выключена
- `GET /api/music/search?q=`, `GET /api/music/track?source=&id=`, `GET /api/music/preview?source=&id=` (заголовок `X-Deezer-Bpm`)

## Темп: как не удвоить и не поделить

Проверено на 16 превью: `web-audio-beat-detector` в диапазоне 60–180 делит пополам почти всю танцевальную музыку
(Summer 128 → 64), а BPM Deezer удваивает баллады (All of Me 63 → 126). Поэтому `decideTempo` смотрит на бас:
периодичные басовые атаки (< 150 Гц) — это ритм-секция, темп из диапазона 90–180, октава по автокорреляции баса;
иначе (баллада) — диапазон 60–180. Deezer решает только неоднозначные случаи.
